# 🛡️ 坦克大战 · Tank Battle

一个用纯 HTML + CSS + JavaScript（Canvas）实现的经典坦克对战小游戏，**无需任何依赖、无需构建**，双击 `index.html` 即可在浏览器中运行。

## 🎮 玩法

- 控制己方坦克，**守住下方的基地旗帜**，消灭所有敌方坦克。
- 砖墙可以被子弹击毁（用来开路），钢墙不可破坏。
- 消灭敌人可获得分数，敌人有概率掉落道具。
- 基地被敌人击毁 / 生命耗尽 → 游戏结束；消灭本关全部敌人 → 进入下一关。

## 🕹️ 操作

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` 或 `↑` `←` `↓` `→` | 移动 |
| `空格` | 射击 |
| `P` | 暂停 / 继续 |
| `Enter` | 开始 / 重新开始 |

## ✨ 特性

- 4 方向移动与射击，像素风 Canvas 渲染
- 砖墙 / 钢墙 / 基地旗帜三类地形
- 敌方坦克 AI（自动巡逻、射击、追踪基地）
- 关卡递进（敌人数量、速度、射速逐步提升）
- 道具系统：❤ 加命、⚡ 速射、🛡 护盾
- 粒子爆炸特效 + Web Audio 合成音效
- 分数 / 生命 / 关卡 / 剩余敌人 HUD

## 🚀 运行

直接打开 `index.html`，或本地起一个静态服务：

```bash
# 任选其一
python -m http.server 8080
# 或
npx serve .
```

然后访问 http://localhost:8080
